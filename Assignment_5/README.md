# Assignment 5 - Naive Bayes on Titanic Dataset

This is my submission for Module 22 where I learned how to use the Naive Bayes algorithm to predict who survived the Titanic disaster.

## How to Run
1. Make sure you have python installed and the libraries `pandas`, `numpy`, `matplotlib`, and `scikit-learn` installed. You can install them by running `pip install pandas numpy matplotlib scikit-learn` in your terminal.
2. Open the `Naive_Bayes_Titanic.ipynb` file in Jupyter Notebook, VS Code, or upload it to Google Colab.
3. Make sure the `Titanic-Dataset.csv` file is in the same folder as the notebook.
4. Click "Run All" to run all the code cells from top to bottom.
